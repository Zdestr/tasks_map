## 🎯 Запуск приложения

### Убедитесь, что порты свободны

Приложение использует:
- **Порт 5000** - для backend сервера
- **Порт 3000** - для frontend приложения

Если порты заняты, освободите их или измените порты в файлах:
- Backend: [`server/index.js`](server/index.js) - строка `const PORT = 5000;`
- Frontend будет предлагать альтернативный порт автоматически

### Запуск

```bash
cd ~/Desktop/planner
npm run dev
```

Или используйте скрипт:
```bash
./start.sh
```

После запуска откройте браузер: **http://localhost:3000**

## 🆘 Возможные проблемы

### Порт занят
```
Error: listen EADDRINUSE: address already in use
```

**Решение:** Остановите процесс на порту или измените порт:
```bash
# Найти процесс на порту 5000
lsof -ti:5000

# Остановить процесс (замените PID)
kill -9 <PID>
```

### Модули не найдены
```
Error: Cannot find module
```

**Решение:** Переустановите зависимости:
```bash
npm run install-all
```
