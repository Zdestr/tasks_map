# 🔄 Как правильно перезапустить приложение

## Шаг 1: Полная остановка

### Вариант А: Ctrl+C в терминале
Нажмите `Ctrl+C` в терминале где запущено `npm run dev`

### Вариант Б: Принудительная остановка
Если Ctrl+C не помог, выполните:

```bash
# Остановить все процессы на портах
kill -9 $(lsof -ti:5000)  # Backend
kill -9 $(lsof -ti:3000)  # Frontend

# Или остановить все Node процессы
pkill -9 node
```

## Шаг 2: Перезапуск

```bash
cd ~/Desktop/planner
npm run dev
```

Дождитесь сообщений:
```
Server is running on http://localhost:5000
Compiled successfully!
```

## Шаг 3: Очистка кэша браузера

После перезапуска сервера, в браузере:

### Chrome/Edge
1. Откройте DevTools (`Cmd+Option+I` на Mac)
2. **Кликните правой кнопкой** на кнопку обновления ⟳
3. Выберите **"Очистить кэш и жесткая перезагрузка"** (Empty Cache and Hard Reload)

### Или через клавиатуру:
- **Mac:** `Cmd+Shift+R` или `Cmd+Option+R`
- **Windows:** `Ctrl+Shift+R` или `Ctrl+F5`

### Safari
- `Cmd+Option+E` (очистить кэш)
- Затем `Cmd+R` (обновить)

## ✅ Проверка изменений

После перезагрузки проверьте:

1. **В форме создания задачи** должно быть:
   - ✅ Поле для ввода символа (текстовое поле, не кнопки)
   - ✅ Подсказка: "Например: 📝, A, 🔥, #1"

2. **В левой панели** внизу должна появиться:
   - ✅ Кнопка "📖 Легенда символов"

3. **В консоли браузера** (F12 → Console):
   - ❌ Не должно быть ошибок 403

## 🔍 Если изменения все еще не видны

### 1. Проверьте версию файлов
```bash
# В терминале проекта
cat client/src/components/TaskModal.js | grep "Символ"
```

Должно быть: `label>Символ * (введите любой символ или emoji)</label`

### 2. Пересборка с нуля
```bash
# Остановить все
pkill -9 node

# Очистить build
cd ~/Desktop/planner/client
rm -rf build node_modules/.cache

# Перезапустить
cd ~/Desktop/planner
npm run dev
```

### 3. Проверьте что открыли правильный URL
- ✅ Правильно: `http://localhost:3000`
- ❌ Неправильно: `http://localhost:5000`

## 💡 Быстрая команда для полного перезапуска

Скопируйте и выполните одной командой:

```bash
pkill -9 node; cd ~/Desktop/planner && npm run dev
```

Эта команда:
1. Останавливает все Node процессы
2. Переходит в папку проекта
3. Запускает приложение заново
