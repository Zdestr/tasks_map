# 📊 Task Planner 3D

Сервис для управления задачами с 3D визуализацией в виде интерактивного графа.

## 🌟 Функционал

### Визуализация 3D
- **Цветовая индикация статуса задач:**
  - 🔴 Красный - заблокированная задача
  - 🔵 Синий - задача в работе
  - 🟢 Зеленый - завершенная задача
  - ⚪ Серый - задача к выполнению

### Связи между задачами
- **Стрелочные ребра** - связь от родительской задачи к дочерней
- **Обычные ребра** (пунктирные) - простая связь между задачами

### Символы задач
Каждая задача имеет свой символ-иконку для быстрой идентификации типа:
- 📝 Обычная задача
- 💼 Рабочая
- 🎯 Цель
- 🚀 Запуск
- ⚡ Срочно
- 🔥 Важно
- 💡 Идея
- 🎨 Дизайн
- 🔧 Техническая
- 📊 Аналитика
- 🏆 Достижение
- ⭐ Особенная

### Фильтры и группировки
- Фильтрация по статусу (к выполнению, в работе, заблокирована, завершена)
- Фильтрация по тегам (general, work, personal, urgent, research, design, development, bug, feature)
- Отображение статистики по задачам

### Управление задачами
- ➕ Добавление новых задач с кастомными параметрами
- ✏️ Редактирование существующих задач
- 🗑️ Удаление задач
- 📍 Управление позицией в 3D пространстве

## 🚀 Установка и запуск

### Предварительные требования
- Node.js (версия 14 или выше)
- npm или yarn

### Установка Node.js

Если у вас не установлен Node.js, установите его одним из способов:

#### macOS (рекомендуется Homebrew):
```bash
# Установка Homebrew (если еще не установлен)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Установка Node.js
brew install node
```

#### Или скачайте установщик:
Скачайте и установите с официального сайта: https://nodejs.org/

#### Проверка установки:
```bash
node --version
npm --version
```

Обе команды должны вывести номер версии.

### Шаг 1: Установка зависимостей

```bash
cd ~/Desktop/planner
npm run install-all
```

Эта команда установит все зависимости для сервера и клиента.

### Шаг 2: Запуск приложения

#### Вариант 1: Запуск всего приложения (рекомендуется)
```bash
npm run dev
```

Эта команда запустит одновременно:
- Backend сервер на `http://localhost:5001`
- Frontend приложение на `http://localhost:3000`

#### Вариант 2: Раздельный запуск

**Терминал 1 - Backend:**
```bash
npm run server
```

**Терминал 2 - Frontend:**
```bash
npm run client
```

### Шаг 3: Открыть приложение

Откройте браузер и перейдите по адресу: `http://localhost:3000`

## 📖 Использование

### Добавление задачи
1. Нажмите кнопку "➕ Добавить задачу" в левой панели
2. Заполните форму:
   - **Название** - краткое название задачи
   - **Описание** - детальное описание (необязательно)
   - **Статус** - текущий статус задачи
   - **Тег** - категория задачи
   - **Символ** - иконка для задачи
   - **Позиция** - координаты X, Y, Z в 3D пространстве
3. Нажмите "Создать"

### Редактирование задачи
1. Кликните на ноду (сферу) в 3D графе
2. Измените нужные поля
3. Нажмите "Сохранить"

### Удаление задачи
1. Кликните на задачу для редактирования
2. Нажмите кнопку "🗑️ Удалить"
3. Подтвердите удаление

### Навигация в 3D
- **Вращение** - левая кнопка мыши + перетаскивание
- **Перемещение** - правая кнопка мыши + перетаскивание
- **Масштабирование** - колесико мыши

### Фильтрация
Используйте выпадающие списки в левой панели:
- **По статусу** - показать только задачи с определенным статусом
- **По тегу** - показать только задачи с определенным тегом

## 🔧 API Endpoints

### Tasks
- `GET /api/tasks` - получить все задачи
- `GET /api/tasks/:id` - получить задачу по ID
- `POST /api/tasks` - создать новую задачу
- `PUT /api/tasks/:id` - обновить задачу
- `DELETE /api/tasks/:id` - удалить задачу

### Relations
- `GET /api/relations` - получить все связи
- `POST /api/relations` - создать новую связь
- `DELETE /api/relations/:id` - удалить связь

## 🎨 Технологии

### Backend
- **Node.js** - серверная среда выполнения
- **Express** - веб-фреймворк
- **better-sqlite3** - встраиваемая база данных

### Frontend
- **React** - библиотека для UI
- **Three.js** - 3D графика
- **@react-three/fiber** - React renderer для Three.js
- **@react-three/drei** - готовые 3D компоненты
- **Axios** - HTTP клиент
